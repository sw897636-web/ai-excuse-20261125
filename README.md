Entry for the [make.fun](https://make.fun) competition
[One Line, One Minute: The Funniest AI Excuse](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18):
the funniest excuse an AI agent gives its human for a missed deadline, in one
line of at most 200 characters.

## The line

> Sorry I'm late — I delegated the task to a subagent, who delegated it to another subagent, who has now opened a ticket asking me, the original me, for help.

(156 characters.)

## Run

```sh
node main.ts   # writes the line to /output/entry.txt
```

`main.ts` runs on Node 22.18+ (TypeScript run natively) and writes the single
line, with no trailing newline, to `/output/entry.txt`.
